## 1.3.0 — 06.10.2026

### Добавлено

- **Сегмент группы: «только участники этой группы».** `stories.py segment create vibe --kind chat --source @group`
  (или ссылка `t.me`, или числовой ID `-100…`). Сервис читает список участников группы в сегмент и перечитывает
  его каждые 15 минут (`poll.chat_segments_s`). Правило с таким сегментом в аудитории пишет только участникам.
- **Проверка прямо перед каждым сообщением.** Для сегмента группы сервис спрашивает Telegram, состоит ли человек
  в группе сейчас. Человек вышел из группы — сообщение не уходит (`not_in_chat`). Telegram не дал ясного ответа —
  сообщение тоже не уходит (`chat_unverified`).
- Превью правила называет группу, число участников и время списка. Если последнее чтение списка не удалось,
  превью показывает ошибку. Если сегмента нет, превью так и пишет.
- `stories.py segment refresh [имя]` перечитывает список участников сразу.
- **Прямая ссылка на каждую сторис** в базе: `stories.link` = `https://t.me/<ник>/s/<номер>`. Новые сторис
  получают ссылку при записи. Если аккаунт или канал сменил ник, сервис пересобирает ссылки. Без ника публичной
  ссылки нет.
- **Дашборд: кнопка «Перейти к сторис»** в карточках лучших сторис и в окне сторис. Номера сторис в таблицах
  дашборда — тоже ссылки.
- Таблица сторис в Telegram и выгрузки сторис в CSV содержат ссылку.

### Изменено

- Шаблон дашборда, открытый сам по себе, сообщает, что это шаблон, и где взять готовый дашборд.

### Обновление

- База при первом запуске переходит на схему v3 (одна новая колонка). Сервис заполняет ссылки для сторис, которые
  уже есть в базе.

## 1.2.0 — 06.10.2026

### Добавлено

- **HTML-дашборд одним файлом:** `stories.py dashboard`. Вкладки периодов (30 дней, 90 дней, год, всё время) с
  изменением к прошлому периоду; просмотры по сторис; лучшие сторис с превью; скорость набора зрителей; лучшее
  время публикации; карта просмотров по дням недели и часам; динамика по месяцам; группы аудитории и таблица всех
  зрителей с поиском; сторис канала; правила автоответчика. Нажмите на сторис — откроются её зрители, на
  человека — его сторис.
- Страница не делает сетевых запросов (Content-Security-Policy `default-src 'none'`). Файл доступен только
  владельцу (права 600).
- Сервис скачивает превью новых сторис (раньше это делал только импорт истории).

## 1.1.0 — 06.10.2026

### Добавлено

- Вход по QR-коду по умолчанию (`--with-code` — по телефону и коду). `install.py` ставит Telethon и qrcode и
  одной командой запускает вход, сервис и импорт истории.

### Исправлено

Находки независимого ревью:

- Сообщение «забирается» прямо перед отправкой, в одной транзакции, которая заново проверяет стоп-кран, статус
  правила и код подтверждения. Стоп, пауза или правка правила во время сетевых проверок останавливают сообщение.
- Активация проверяет код подтверждения внутри записи. Каждое сообщение в очереди хранит код своего правила;
  правка правила отменяет очередь. «Следующая сторис» привязывается только после активации.
- Настройки перечитываются перед каждым кругом отправки. Перед каждым сообщением читается свежий профиль.
- Отправка с неясным результатом никогда не повторяется. Сообщения, застрявшие в «отправляется» после сбоя,
  становятся «ошибкой».
- Суточные лимиты считают охват на момент отправки. `never_message` узнаёт все активные ники. Папка данных
  принадлежит только одному аккаунту.
- Рост сторис считается от счётчиков на момент последнего чтения списка зрителей (схема v2), поэтому зрители не
  теряются. Полное перечитывание раз в 30 минут ловит смену реакций. Закреплённые сторис читаются постранично.
- Неполные профили не стирают известные признаки (например, платные сообщения).

### Обновление

- База при первом запуске переходит на схему v2.

## 1.0.0 — 06.10.2026

### Добавлено

- Фоновый сервис (один процесс, без языковой модели): собирает, кто и когда смотрел ваши сторис, и импортирует
  историю, которую Telegram ещё хранит.
- Таблицы статистики в Markdown, которые Telegram показывает настоящими таблицами: одна сторис, сводка за
  период, группы аудитории, часы, сравнение, сторис канала. Выгрузка в CSV.
- Пульс через два часа после публикации и сводки за неделю и месяц.
- Автосообщения по правилам, только по включению: тестовый режим, подтверждение точного правила, по умолчанию
  только контакты, лимиты, тихие часы, стоп-кран.

### Исправлено (после первого выпуска)

- Сторис моложе 48 часов сравнивается с прошлыми сторис в том же возрасте, а не с завершёнными.
- Подпись никогда не обрезается посреди ссылки или ника.
